# Changelog

## [0.1.0] - 2026-10-19

### Added
- Profiles and commits in an editor tab: link previews, images, code blocks, replies toggle, pagination.
- Sidebar: username field, your profile, and the people you follow.
- Commit composer: new commits, replies and up to 3 images, signed with the SSH key on your GitHub account.
- Commit Selection: opens the composer with the selected code in a fenced block.
